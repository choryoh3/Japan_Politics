# 政治人事データベース（japan-politics）

## 概要
歴代の日本の内閣（総理大臣・閣僚・内閣官房副長官・副大臣・大臣政務官）、各省庁の事務方（事務次官・官房長・局長・審議官・課長）、与党・自由民主党の党人事（党役員・政務調査会の部会・調査会）を、1つのアプリで素早く検索・閲覧できる人事データベース。
初期データには、首相官邸・各府省・自由民主党などの公式に公表された実在の人事を収録し、人事ごとに出典（URL・メモ）を表示する。
管理者は人物・内閣・人事と出典をその場で作成・修正でき、修正はすぐに全画面（内閣名簿・省庁ページ・人物の経歴・検索）へ反映される。

## ターゲットユーザー
- 政治記者・編集者: 記事執筆中に「この日の幹事長は誰か」「この人物の過去の役職は何か」を数秒で確かめ、出典を開いて裏取りしたい。
- 政策・政治の研究者、学生: 内閣ごと・省庁ごと・党役職ごとの歴代在任者を一覧で比べたい。
- 議員事務所・官公庁・業界団体の調査担当: 省庁の政務三役や事務次官・局長・審議官・課長の顔ぶれを素早く把握したい。
- データの管理者: 新しい人事が公表されたら、出典を添えて追記・修正したい。

## 機能一覧

| 優先度 | 機能 | ユーザーができること |
|---|---|---|
| 高 | 実在の初期データ | 公式に公表された実在の内閣・省庁・党の人事が、出典付きで最初から入っている状態で使い始める |
| 高 | 内閣一覧・内閣詳細 | 歴代内閣を新しい順に一覧し、内閣ごとの閣僚名簿（総理大臣・官房長官・各大臣）を出典とともに見る |
| 高 | 人物ページ | 人物ごとに、内閣・省庁・党のすべての役職の経歴を、各人事の出典とともに時系列で見る |
| 高 | 横断検索 | ヘッダーの検索欄から、人物名（漢字・よみがな）・内閣名・役職名・部会名で即座に目的のページへ移動する |
| 高 | ログインと管理者ロール | アカウントを登録・ログインできる。作成・修正・削除は管理者だけができ、一般ユーザーと未ログインの利用者は閲覧だけができる |
| 高 | 人物の作成・修正・削除 | 管理者が人物（氏名・よみがな等）を追加・修正し、経歴のない人物を削除する |
| 高 | 内閣と閣僚人事の作成・修正 | 管理者が内閣を追加・修正し、閣僚人事を出典（URL・メモ）付きで追加・修正・削除する |
| 高 | 内閣の詳細人事 | 内閣官房副長官・副大臣・大臣政務官を内閣ごとに区分して見る。管理者は追加・修正する |
| 中 | 省庁ページ | 省庁ごとに、歴代の大臣・副大臣・大臣政務官を見る |
| 中 | 省庁の事務方人事（幹部） | 省庁ごとに、事務次官・官房長・局長の歴代を見る。管理者は追加・修正し、局を追加する |
| 中 | 省庁の事務方人事（審議官・課長） | 省庁ごとに、審議官・課長の歴代を見る。管理者は追加・修正し、課を追加する |
| 高 | 自民党の党役員人事 | 指定した日付時点の総裁・副総裁・幹事長・幹事長代行・総務会長・政務調査会長・衆参の国会対策委員長を見る。役職ごとの歴代を見る。管理者は党役員人事を追加・修正する |
| 中 | 政務調査会の部会・調査会人事 | 部会・調査会ごとの部会長・調査会長などを見る。管理者は人事と部会・調査会を追加・修正する |
| 中 | 党役職の追加 | 管理者が、依頼にない党役職（例: 選挙対策委員長）を追加して管理する |
| 低 | ライト / ダーク表示の切替 | 画面の配色を切り替え、選択を保持する |

## 非目標
- 自民党以外の政党（連立相手を含む）の党人事
- 国会の委員会人事（常任委員長など）、地方自治体の人事
- 外部の公式サイト・官報などからの、アプリ実行中のデータ自動取り込み・スクレイピング（初期データは投入用データとしてリポジトリに収録する）
- 公式データとユーザー（管理者）による修正の、画面上での区別
- 人事データの変更履歴（版管理）・差し戻し機能、編集の承認フロー
- 管理者・一般ユーザー以外のロール（編集者・閲覧者の細分化など）、画面からの管理者の付与・剥奪
- 人物の顔写真などの画像管理
- CSV などのインポート / エクスポート
- 英語など日本語以外の UI
- 2001 年の中央省庁再編より前の旧省庁（大蔵省など）の省庁ページ
- 事務方の役職のうち、事務次官・官房長・局長・審議官・課長以外（財務官・外務審議官などの次官級、部長、室長、課長補佐など）
- 初期データの網羅性の保証（収録範囲は各スプリントの契約で定めた範囲とし、すべての歴代人事は収録しない）

## 前提と未確定事項
- 初期データは、首相官邸・各府省・自由民主党の公式ウェブサイトなど、公式に公表された資料に基づく実在の人事とする。収録範囲は次のとおり（範囲外の人事は、管理者が後から追加する）。
  - 内閣と閣僚人事: 菅内閣（2020年9月16日発足）から、データ投入時点の最新の内閣まで（Sprint 1）
  - 内閣官房副長官・副大臣・大臣政務官: 最新の内閣とその 1 つ前の内閣（Sprint 5）
  - 事務次官: 11 省（総務・法務・外務・財務・文部科学・厚生労働・農林水産・経済産業・国土交通・環境・防衛）の、データ投入時点の在任者と、2020年以降の前任者（Sprint 6）
  - 官房長・局長: 財務省と外務省（Sprint 6）。審議官・課長: 財務省（Sprint 7）
  - 党役員 8 役職: 菅義偉総裁の就任（2020年9月）以降（Sprint 8）
  - 政務調査会の部会・調査会: データ投入時点の部会・調査会と、その長の在任者（Sprint 9）
- 初期データは Generator が公式資料を確認して作成し、各人事に出典 URL（公式ページ）と、必要なら出典メモ（例: 「首相官邸 第1次石破内閣 閣僚名簿」）を付ける。アプリは正確性を自動では検証しない。データの誤りは管理者が画面から修正する。
- 出典は人事（任命）ごとに 1 件（URL 1 つとメモ 1 つ）を持つ。管理者が人事を追加・修正するとき、出典 URL と出典メモは任意入力とする。出典 URL を入力する場合は `http://` または `https://` で始まる URL に限る。
- 出典は、内閣詳細画面の閣僚名簿と、人物ページの経歴の各行に表示する。人物ページの経歴にはすべての種類の人事が載るため、すべての人事の出典を人物ページで確認できる。
- 閲覧はログイン不要で誰でもできる。アカウント登録は誰でもできるが、登録したユーザーは「一般ユーザー」で、閲覧だけができる。
- 作成・修正・削除は「管理者」だけができる。最初の管理者は、登録済みのアカウントのメールアドレスを指定して実行する管理者付与コマンド（コマンド名は Generator が決め、`docs/project.md` の「初期データ・準備」に記載する）で作る。画面から管理者を付与・剥奪する機能は作らない。
- 内閣改造は、別の「内閣」として登録する（例: 「第2次岸田内閣」と「第2次岸田第1次改造内閣」は別の内閣）。内閣名は首相官邸の表記に合わせる。
- 人事（任命）は「人物・役職・所属（内閣／省庁／党）・就任日・退任日（在任中は空）・出典 URL・出典メモ」で表す。日付は日単位。
- 単独の役職（内閣総理大臣、内閣官房長官、各省大臣、事務次官、官房長、局長、課長、党役員の各役職、部会長など）は、同じ所属で在任期間が重なる人事を登録できない。複数人が同時に就く役職（内閣官房副長官、副大臣、大臣政務官、特命担当の国務大臣、審議官など）は重複を許す。
- 事務方の役職は、事務次官・官房長・局長・審議官・課長とする。局長は局ごと、課長は課ごとの単独の役職とする。審議官は省庁ごとに、正式な官職名（例: 「大臣官房審議官（主計局担当）」）をそのまま記録する。課は大臣官房または局に属する。
- 自民党の部会役職は、部会長・部会長代理・調査会長・事務局長とする。
- 省庁は現行の府省（2001 年再編以降）を対象とする。
- 与党は自由民主党に固定する。
