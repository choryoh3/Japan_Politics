# 政治人事データベース（japan-politics）

## 概要
歴代の日本の内閣（総理大臣・閣僚・内閣官房副長官・副大臣・大臣政務官）、各省庁の事務方（事務次官以下）、与党・自由民主党の党人事（党役員・政務調査会の部会・調査会）を、1つのアプリで素早く検索・閲覧できる人事データベース。
ログインしたユーザーは、人物・内閣・人事をその場で作成・修正でき、修正はすぐに全画面（内閣名簿・省庁ページ・人物の経歴・検索）へ反映される。

## ターゲットユーザー
- 政治記者・編集者: 記事執筆中に「この日の幹事長は誰か」「この人物の過去の役職は何か」を数秒で確かめたい。
- 政策・政治の研究者、学生: 内閣ごと・省庁ごと・党役職ごとの歴代在任者を一覧で比べたい。
- 議員事務所・官公庁・業界団体の調査担当: 省庁の政務三役や事務次官・局長の顔ぶれを素早く把握し、最新の人事を自分で追記したい。

## 機能一覧

| 優先度 | 機能 | ユーザーができること |
|---|---|---|
| 高 | 内閣一覧・内閣詳細 | 歴代内閣を新しい順に一覧し、内閣ごとの閣僚名簿（総理大臣・官房長官・各大臣）を見る |
| 高 | 人物ページ | 人物ごとに、内閣・省庁・党のすべての役職の経歴を時系列で見る |
| 高 | 横断検索 | ヘッダーの検索欄から、人物名（漢字・よみがな）・内閣名・役職名・部会名で即座に目的のページへ移動する |
| 高 | ログインと編集権限 | アカウントを登録・ログインし、ログイン中だけ作成・修正・削除ができる |
| 高 | 人物の作成・修正・削除 | 人物（氏名・よみがな等）を追加・修正し、経歴のない人物を削除する |
| 高 | 内閣と閣僚人事の作成・修正 | 内閣を追加・修正し、閣僚人事を追加・修正・削除する |
| 高 | 内閣の詳細人事 | 内閣官房副長官・副大臣・大臣政務官を内閣ごとに区分して見る・追加・修正する |
| 中 | 省庁ページ | 省庁ごとに、歴代の大臣・副大臣・大臣政務官を見る |
| 中 | 省庁の事務方人事 | 省庁ごとに、事務次官・官房長・局長の歴代を見る・追加・修正し、部局を追加する |
| 高 | 自民党の党役員人事 | 指定した日付時点の総裁・副総裁・幹事長・幹事長代行・総務会長・政務調査会長・衆参の国会対策委員長を見る。役職ごとの歴代を見る。党役員人事を追加・修正する |
| 中 | 政務調査会の部会・調査会人事 | 部会・調査会ごとの部会長・調査会長などを見る・追加・修正し、部会・調査会を追加する |
| 中 | 党役職の追加 | 依頼にない党役職（例: 選挙対策委員長）をユーザーが追加して管理する |
| 低 | ライト / ダーク表示の切替 | 画面の配色を切り替え、選択を保持する |

## 非目標
- 自民党以外の政党（連立相手を含む）の党人事
- 国会の委員会人事（常任委員長など）、地方自治体の人事
- 外部の公式サイト・官報などからのデータ自動取り込み、スクレイピング
- 人事データの変更履歴（版管理）・差し戻し機能、編集の承認フロー、管理者などの権限ロール
- 人物の顔写真などの画像管理
- CSV などのインポート / エクスポート
- 英語など日本語以外の UI
- 2001 年の中央省庁再編より前の旧省庁（大蔵省など）の省庁ページ
- 初期データの網羅性・正確性の保証（初期データは検証用）

## 前提と未確定事項
- 初期データは動作検証用であり、実在の人事と一致するとは限らない。実在の人物名・内閣名を使う場合も、正確性は保証しない。
- 閲覧はログイン不要で誰でもできる。作成・修正・削除はログインしたユーザーなら誰でもできる（ロールによる区別はしない）。アカウント登録は誰でもできる。
- 内閣改造は、別の「内閣」として登録する（例: 「第2次○○内閣」と「第2次○○改造内閣」は別の内閣）。
- 人事（任命）は「人物・役職・所属（内閣／省庁／党）・就任日・退任日（在任中は空）」で表す。日付は日単位。
- 単独の役職（内閣総理大臣、内閣官房長官、各省大臣、事務次官、党役員の各役職、部会長など）は、同じ所属で在任期間が重なる人事を登録できない。複数人が同時に就く役職（内閣官房副長官、副大臣、大臣政務官、特命担当の国務大臣など）は重複を許す。
- 省庁は現行の府省（2001 年再編以降）を対象とする。
- 公式データとユーザー修正の区別、データの出典の記録は、本仕様では扱わない（確認事項）。
- 与党は自由民主党に固定する。
