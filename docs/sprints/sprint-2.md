## Sprint 2: 人物ページと横断検索

### 目的
閣僚名簿から人物ページへ移動して経歴を出典とともに時系列で確認でき、どの画面からでもヘッダーの検索欄で人物・内閣へすぐに移動できる。配色をライト / ダークで切り替えられる。

### 実装する機能
- 人物ページ: 氏名・よみがなと、就任したすべての役職の経歴を、各人事の出典とともに就任日の新しい順で表示する
- 横断検索: ヘッダーの検索欄で、人物（氏名・よみがな）と内閣（内閣名）を入力中に候補表示し、選ぶとそのページへ移動する
- ライト / ダーク表示の切替: ヘッダーのボタンで配色を切り替え、選択を保持する

### 対象外（このスプリントでやらないこと）
- ログイン、管理者ロール、データの作成・修正・削除（Sprint 3 以降）
- 役職名・部会名での検索（Sprint 8、Sprint 9）
- 検索結果の専用ページ（候補表示のみとする）

### 前提（初期データ）
- Sprint 1 の実在の初期データを使う。「加藤勝信」は「菅内閣」の内閣官房長官と「第1次石破内閣」の財務大臣を務めており、同一人物として 1 人で登録されている
- すべての人物によみがな（ひらがな）が登録されている

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 内閣詳細画面の閣僚名簿で氏名をクリックすると、その人物のページに移動し、見出しに氏名、その近くによみがなが表示される
- [ ] 人物ページに「経歴」の一覧があり、各行に役職名・所属（内閣名）・就任日・退任日・出典の 5 項目が表示される
- [ ] 人物ページの経歴は就任日の新しい順に並ぶ
- [ ] 「加藤勝信」の人物ページの経歴に、所属「菅内閣」・役職「内閣官房長官」の行と、所属「第1次石破内閣」・役職「財務大臣」の行の両方が表示される
- [ ] 人物ページの経歴で内閣名をクリックすると、その内閣の詳細画面に移動する
- [ ] 存在しない人物 ID の人物ページの URL を直接開くと、「人物が見つかりません」と表示される
- [ ] トップページ・内閣詳細画面・人物ページのヘッダーに、プレースホルダー「人物・内閣を検索」の検索欄がある
- [ ] 検索欄に「石破」と入力すると、入力を止めてから 1 秒以内に、「石破茂」が「人物」見出しの下に候補として表示される
- [ ] 検索欄に「かとうかつ」と入力すると、「加藤勝信」が候補に表示される
- [ ] 検索欄に「岸田」と入力すると、「第1次岸田内閣」が「内閣」見出しの下に候補として表示される
- [ ] 検索欄に「zzzzz」と入力すると、「該当する結果はありません」と表示される
- [ ] 検索欄に入力して候補が出た状態で、下矢印キーで候補を選び Enter キーを押すと、その候補のページに移動する
- [ ] ヘッダーの配色切替ボタンを押すと `body` の背景色が変わり、ページを再読み込みしても切り替えた配色のまま表示される
- [ ] トップページと人物ページの `html` 要素の `lang` 属性が `ja` である
- [ ] 回帰: トップページで内閣名をクリックすると内閣詳細画面が開き、閣僚名簿の 1 行目の役職が「内閣総理大臣」である
