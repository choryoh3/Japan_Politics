## Sprint 2: 人物ページと横断検索

### 目的
閣僚名簿から人物ページへ移動して経歴を時系列で確認でき、どの画面からでもヘッダーの検索欄で人物・内閣へすぐに移動できる。配色をライト / ダークで切り替えられる。

### 実装する機能
- 人物ページ: 氏名・よみがなと、就任したすべての役職の経歴を就任日の新しい順で表示する
- 横断検索: ヘッダーの検索欄で、人物（氏名・よみがな）と内閣（内閣名）を入力中に候補表示し、選ぶとそのページへ移動する
- ライト / ダーク表示の切替: ヘッダーのボタンで配色を切り替え、選択を保持する

### 対象外（このスプリントでやらないこと）
- ログイン、データの作成・修正・削除（Sprint 3 以降）
- 役職名・部会名での検索（Sprint 7、Sprint 8）
- 検索結果の専用ページ（候補表示のみとする）

### 前提（初期データ）
- 2 つ以上の内閣で閣僚を務めた人物を 1 名以上含める
- すべての人物によみがな（ひらがな）を登録する

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 内閣詳細画面の閣僚名簿で氏名をクリックすると、その人物のページに移動し、見出しに氏名、その近くによみがなが表示される
- [ ] 人物ページに「経歴」の一覧があり、各行に役職名・所属（内閣名）・就任日・退任日の 4 項目が表示される
- [ ] 人物ページの経歴は就任日の新しい順に並ぶ
- [ ] 2 つ以上の内閣で閣僚を務めた初期データの人物のページでは、経歴が 2 行以上表示される
- [ ] 人物ページの経歴で内閣名をクリックすると、その内閣の詳細画面に移動する
- [ ] 存在しない人物 ID の人物ページの URL を直接開くと、「人物が見つかりません」と表示される
- [ ] トップページ・内閣詳細画面・人物ページのヘッダーに、プレースホルダー「人物・内閣を検索」の検索欄がある
- [ ] 検索欄に初期データの人物の氏名の一部（漢字 2 文字）を入力すると、入力を止めてから 1 秒以内に、その人物が「人物」見出しの下に候補として表示される
- [ ] 検索欄に初期データの人物のよみがなの一部（ひらがな 3 文字）を入力すると、その人物が候補に表示される
- [ ] 検索欄に初期データの内閣名の一部を入力すると、その内閣が「内閣」見出しの下に候補として表示される
- [ ] 検索欄に「zzzzz」と入力すると、「該当する結果はありません」と表示される
- [ ] 検索欄に空白だけを入力しても、候補の一覧もエラーも表示されない
- [ ] 検索欄に入力して候補が出た状態で、下矢印キーで候補を選び Enter キーを押すと、その候補のページに移動する
- [ ] ヘッダーの配色切替ボタンを押すと `body` の背景色が変わり、ページを再読み込みしても切り替えた配色のまま表示される
- [ ] 回帰: トップページで内閣名をクリックすると内閣詳細画面が開き、閣僚名簿の 1 行目の役職が「内閣総理大臣」である
