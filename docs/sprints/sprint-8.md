## Sprint 8: 政務調査会の部会・調査会人事と党役職の追加

### 目的
自民党政務調査会の部会・調査会ごとに、部会長・調査会長などの在任者と歴代を確認でき、ログイン中のユーザーが部会・調査会とその人事、さらに 8 役職以外の党役職を追加できる。

### 実装する機能
- 部会・調査会の一覧とページ: 「部会」「調査会」の区分で一覧し、各ページで指定日時点の在任者と役職ごとの歴代を表示する
- 部会・調査会の追加と人事の追加・修正・削除: 部会・調査会を追加し、部会長・部会長代理・調査会長・事務局長の人事を管理する
- 党役職の追加: 党役員ページに表示する党役職（例: 選挙対策委員長）をユーザーが追加する

### 対象外（このスプリントでやらないこと）
- 部会・調査会・党役職の削除と名称変更
- 部会・調査会の下の小委員会・プロジェクトチーム
- 党役職の表示順の並べ替え（追加した役職は末尾に表示する）

### 前提（初期データ）
- 「財務金融部会」を含む部会を 3 つ以上、調査会を 2 つ以上登録し、それぞれに長（部会長・調査会長）の人事を 1 件以上含める

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 党役員ページの「政務調査会」リンクを押すと、「部会」と「調査会」の 2 つの見出しの下に、それぞれ 3 件以上と 2 件以上の名称が表示される
- [ ] 部会名を押すとその部会のページに移動し、今日時点の「部会長」と「部会長代理」の在任者（在任者がいなければ「空席」）が表示される
- [ ] 部会のページに部会長の歴代が就任日の新しい順に、氏名・就任日・退任日とともに表示される
- [ ] 未ログインの状態では、「部会・調査会を追加」「人事を追加」「役職を追加」が表示されない
- [ ] ログイン中に「部会・調査会を追加」で区分「部会」と名称「テスト部会」を入力して保存すると、「部会」の見出しの下に「テスト部会」が表示される
- [ ] 「部会・調査会を追加」で名称を空のまま保存すると、「名称は必須です」と表示され、追加されない
- [ ] 既にある部会と同じ名称で保存すると、「同じ名前の部会・調査会が既にあります」と表示され、追加されない
- [ ] 部会のページの「人事を追加」で役職「部会長」・人物・就任日を入力して保存すると、その人物が部会長の歴代の 1 行目に表示される
- [ ] 在任者のいる期間に同じ部会の「部会長」をもう 1 人追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、追加されない
- [ ] 財務金融部会の部会長を務めた人物の人物ページの経歴に、役職名「財務金融部会長」と所属「自由民主党 政務調査会」が表示される
- [ ] ヘッダーの検索欄に部会名の一部を入力すると、その部会が「部会・調査会」見出しの下に候補として表示され、選ぶと部会のページに移動する
- [ ] ログイン中に党役員ページの「役職を追加」で「選挙対策委員長」を入力して保存すると、党役員ページの役職一覧の末尾に「選挙対策委員長」が「空席」として表示される
- [ ] 「役職を追加」で既にある役職名「幹事長」を入力して保存すると、「同じ名前の役職が既にあります」と表示され、追加されない
- [ ] 追加した部会・調査会、その人事、党役職は、開発サーバーを再起動した後も表示される
- [ ] 回帰: 党役員ページで日付を前任の総裁の在任期間内に変えると、「総裁」の氏名が前任者に切り替わる
