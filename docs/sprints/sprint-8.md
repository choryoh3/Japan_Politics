## Sprint 8: 自民党の党役員人事

### 目的
指定した日付時点の自民党の党役員（総裁・副総裁・幹事長・幹事長代行・総務会長・政務調査会長・衆参の国会対策委員長）を、菅義偉総裁の就任以降の実在データで一目で確認でき、役職ごとの歴代在任者も見られる。管理者は党役員人事を出典付きで追加・修正できる。

### 実装する機能
- 党役員の時点表示: 日付を指定すると、その日に在任していた 8 役職の在任者を表示する（既定は今日）
- 役職別の歴代一覧: 党役職ごとに歴代在任者を就任日の新しい順で表示し、検索欄から役職名でも移動できる
- 党役員人事の追加・修正・削除: 管理者が党役員ページ・歴代一覧から、出典 URL・出典メモを含めて党役員人事を追加・修正・削除する（退任日は就任日以降に限る）
- 実在の初期データの追加: 8 役職の、2020年9月の菅義偉総裁の就任以降の人事を、出典付きで投入する

### 対象外（このスプリントでやらないこと）
- 政務調査会の部会・調査会の人事（Sprint 9）
- 8 役職以外の党役職の追加（Sprint 9）
- 自民党以外の政党の人事
- 2020年9月の菅義偉総裁の就任より前の党役員の初期データ

### 前提（初期データ）
- 8 役職について、2020年9月の菅義偉総裁の就任以降に在任した人事を登録する（その期間に置かれていなかった役職は登録しない）
- 出典 URL は自由民主党の公式ウェブサイト、または党役員人事を報じた公式の発表のページとする

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] ヘッダーの「党役員」リンクを押すと、見出し「自由民主党 役員」のページに、今日の日付が入った日付欄が表示される
- [ ] 党役員ページに「総裁」「副総裁」「幹事長」「幹事長代行」「総務会長」「政務調査会長」「衆議院国会対策委員長」「参議院国会対策委員長」の 8 役職がこの順に並ぶ
- [ ] 日付欄を「2000-01-01」にすると、8 役職すべてに氏名の代わりに「空席」と表示される
- [ ] 日付欄を「2025-01-01」にすると、「総裁」に「石破茂」、「幹事長」に「森山裕」と表示される
- [ ] 日付欄を「2021-01-01」にすると、「総裁」に「菅義偉」と表示される
- [ ] 日付を変えるとページの URL に日付が含まれ、その URL を新しいタブで開くと同じ日付の党役員が表示される
- [ ] 日付が「2025-13-40」となる URL を直接開くと、「日付が正しくありません」と表示される
- [ ] 党役員ページで役職名「幹事長」を押すと幹事長の歴代一覧に移動し、在任者が就任日の新しい順に、氏名・就任日・退任日とともに表示される
- [ ] ヘッダーの検索欄に「幹事長」と入力すると、「役職」見出しの下に「幹事長」が候補として表示され、選ぶと幹事長の歴代一覧に移動する
- [ ] 「森山裕」の人物ページの経歴に、役職「幹事長」・所属「自由民主党」の行があり、その行の「出典」リンク先 URL が `https://` で始まる
- [ ] 未ログインの状態と一般ユーザーでログインした状態のどちらでも、党役員ページと歴代一覧に「党役員人事を追加」と各行の「編集」「削除」が表示されない
- [ ] 管理者が「党役員人事を追加」で役職・人物・就任日を入力して保存すると、就任日以降の日付を指定した党役員ページにその人物が表示される
- [ ] 在任者のいる期間に同じ党役職の人事をもう 1 件追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、追加されない
- [ ] 歴代一覧の行の「削除」を押し、確認ダイアログで「削除する」を押すと、その行が歴代一覧から消える
- [ ] 回帰: 財務省の省庁ページの「事務方」タブに「事務次官」の見出しと在任者が表示される
