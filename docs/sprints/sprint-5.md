## Sprint 5: 内閣の詳細人事（官房副長官・副大臣・大臣政務官）と省庁ページ

### 目的
内閣ごとに、閣僚に加えて内閣官房副長官・副大臣・大臣政務官を区分して確認・追加でき、省庁ごとに歴代の大臣・副大臣・大臣政務官を一覧できる。

### 実装する機能
- 内閣詳細の区分表示: 内閣詳細画面の人事を「閣僚」「内閣官房副長官」「副大臣」「大臣政務官」の 4 区分に分けて表示する
- 詳細人事の追加・修正・削除: 内閣官房副長官・各省の副大臣・大臣政務官の人事を、閣僚人事と同じ操作で追加・修正・削除する
- 省庁一覧と省庁ページ: 省庁を一覧し、省庁ごとに歴代の大臣・副大臣・大臣政務官を就任日の新しい順で表示する

### 対象外（このスプリントでやらないこと）
- 事務次官以下の事務方人事（Sprint 6）
- 省庁の追加・名称変更（省庁は初期データで用意する）
- 2001 年の中央省庁再編より前の旧省庁

### 前提（初期データ）
- 財務省・外務省を含む 6 以上の府省を登録する
- 少なくとも 1 つの内閣に、内閣官房副長官 2 名以上、副大臣 3 名以上、大臣政務官 3 名以上の人事を含める

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 内閣詳細画面に「閣僚」「内閣官房副長官」「副大臣」「大臣政務官」の 4 つの見出しがこの順に表示される
- [ ] 前提の初期データを持つ内閣の詳細画面で、「内閣官房副長官」の下に 2 名以上、「副大臣」の下に 3 名以上、「大臣政務官」の下に 3 名以上が表示される
- [ ] 「副大臣」「大臣政務官」の各行に、担当省庁名を含む役職名（例: 「財務副大臣」）と氏名が表示される
- [ ] 人事が 1 件もない区分の見出しの下に、「登録された人事はありません」と表示される
- [ ] ログイン中に内閣詳細画面の「人事を追加」の役職の選択肢に、「内閣官房副長官」「財務副大臣」「財務大臣政務官」が含まれる
- [ ] 「人事を追加」で「財務副大臣」の人事を保存すると、内閣詳細画面の「副大臣」の見出しの下にその行が表示される
- [ ] 同じ内閣・同じ期間に「財務副大臣」を 2 人登録しても、エラーにならず 2 行とも表示される
- [ ] ヘッダーの「省庁」リンクを押すと省庁一覧が表示され、「財務省」「外務省」を含む 6 件以上の省庁が表示される
- [ ] 省庁一覧で「財務省」を押すと財務省の省庁ページに移動し、「大臣」「副大臣」「大臣政務官」のタブが表示される
- [ ] 省庁ページの「大臣」タブに歴代の大臣が就任日の新しい順で並び、各行に氏名・内閣名・就任日・退任日が表示される
- [ ] 内閣詳細画面で追加した「財務副大臣」の人事が、財務省の省庁ページの「副大臣」タブにも表示される
- [ ] 省庁ページで氏名をクリックすると、その人物の人物ページに移動する
- [ ] 存在しない省庁 ID の省庁ページの URL を直接開くと、「省庁が見つかりません」と表示される
- [ ] 回帰: ログイン中に内閣を追加し、「内閣総理大臣」の人事を追加すると、内閣詳細画面の「閣僚」の見出しの下に表示される
