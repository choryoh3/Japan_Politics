## Sprint 7: 自民党の党役員人事

### 目的
指定した日付時点の自民党の党役員（総裁・副総裁・幹事長・幹事長代行・総務会長・政務調査会長・衆参の国会対策委員長）を一目で確認でき、役職ごとの歴代在任者も見られる。ログイン中のユーザーは党役員人事を追加・修正できる。

### 実装する機能
- 党役員の時点表示: 日付を指定すると、その日に在任していた 8 役職の在任者を表示する（既定は今日）
- 役職別の歴代一覧: 党役職ごとに歴代在任者を就任日の新しい順で表示し、検索欄から役職名でも移動できる
- 党役員人事の追加・修正・削除: 党役員ページ・歴代一覧から党役員人事を追加・修正・削除する

### 対象外（このスプリントでやらないこと）
- 政務調査会の部会・調査会の人事（Sprint 8）
- 8 役職以外の党役職の追加（Sprint 8）
- 自民党以外の政党の人事

### 前提（初期データ）
- 8 役職すべてに人事を含め、「総裁」は 2 名以上の在任期間を含める（総裁が交代した日付をまたいで表示を比べられるようにする）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] ヘッダーの「党役員」リンクを押すと、見出し「自由民主党 役員」のページに、今日の日付が入った日付欄が表示される
- [ ] 党役員ページに「総裁」「副総裁」「幹事長」「幹事長代行」「総務会長」「政務調査会長」「衆議院国会対策委員長」「参議院国会対策委員長」の 8 役職がこの順に並び、各役職に在任者の氏名が表示される
- [ ] 指定した日付に在任者のいない役職には、氏名の代わりに「空席」と表示される
- [ ] 日付欄を初期データの前任の総裁の在任期間内の日付に変えると、「総裁」の氏名が前任者に切り替わる
- [ ] 日付を変えるとページの URL に日付が含まれ、その URL を新しいタブで開くと同じ日付の党役員が表示される
- [ ] 日付が「2025-13-40」となる URL を直接開くと、「日付が正しくありません」と表示される
- [ ] 党役員ページで役職名「幹事長」を押すと幹事長の歴代一覧に移動し、在任者が就任日の新しい順に、氏名・就任日・退任日とともに表示される
- [ ] ヘッダーの検索欄に「幹事長」と入力すると、「役職」見出しの下に「幹事長」が候補として表示され、選ぶと幹事長の歴代一覧に移動する
- [ ] 党役員人事が登録された人物の人物ページの経歴に、その党役職が所属「自由民主党」として表示される
- [ ] 未ログインの状態では、党役員ページと歴代一覧に「党役員人事を追加」と各行の「編集」「削除」が表示されない
- [ ] ログイン中に「党役員人事を追加」で役職・人物・就任日を入力して保存すると、就任日以降の日付を指定した党役員ページにその人物が表示される
- [ ] 在任者のいる期間に同じ党役職の人事をもう 1 件追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、追加されない
- [ ] 就任日より前の退任日を入力して保存すると、「退任日は就任日以降の日付にしてください」と表示され、保存されない
- [ ] 歴代一覧の行の「削除」を押し、確認ダイアログで「削除する」を押すと、その行が歴代一覧から消える
- [ ] 回帰: 財務省の省庁ページの「事務方」タブに「事務次官」の見出しと在任者が表示される
