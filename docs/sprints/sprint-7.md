## Sprint 7: 省庁の事務方人事（審議官・課長）

### 目的
省庁ページの「事務方」タブで、審議官と課長の歴代も確認できる（財務省は実在データ入り）。管理者は審議官・課長の人事（出典を含む）と課を追加・修正できる。

### 実装する機能
- 審議官の表示と人事管理: 「事務方」タブに「審議官」の見出しを追加し、在任者を正式な官職名（例: 「大臣官房審議官（主計局担当）」）とともに表示する。管理者は審議官の人事を出典付きで追加・修正・削除する
- 課の追加: 管理者が、省庁の大臣官房または局の下に課を追加する
- 課長の表示と人事管理: 「事務方」タブに「課長」の見出しを追加し、所属と課名を含む役職名（例: 「主計局総務課長」「大臣官房秘書課長」）で表示する。管理者は課長の人事を出典付きで追加・修正・削除する
- 実在の初期データの追加: 財務省の審議官と、財務省の大臣官房・主計局の課と課長の人事を、出典付きで投入する

### 対象外（このスプリントでやらないこと）
- 財務省以外の審議官・課長の初期データ
- 財務省の大臣官房・主計局以外の課の初期データ
- 課の削除・名称変更
- 部長・室長・課長補佐など、事務次官・官房長・局長・審議官・課長以外の役職

### 前提（初期データ・規則）
- 財務省の審議官について、データ投入時点の在任者を 5 名以上登録する
- 財務省の大臣官房と主計局の課を合わせて 5 つ以上（「主計局総務課」「大臣官房秘書課」を含む）登録し、各課のデータ投入時点の課長を登録する
- 出典 URL は財務省の公式ウェブサイト（幹部名簿・人事異動の発表など）または官報のページとする
- 審議官は同じ省庁で同時に複数人が在任できる。課長は課ごとに 1 人（在任期間の重複を許さない）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 財務省の「事務方」タブに「事務次官」「官房長」「局長」「審議官」「課長」の 5 つの見出しがこの順に表示される
- [ ] 財務省の「事務方」タブの「審議官」の下に 5 名以上が、官職名・氏名・就任日とともに表示される
- [ ] 財務省の「事務方」タブの「課長」の下に、「主計局総務課長」と「大臣官房秘書課長」を含む 5 行以上が氏名とともに表示される
- [ ] 財務省の「審議官」と「課長」の初期データの各行に「出典」リンクがあり、リンク先 URL が `https://` で始まる
- [ ] 未ログインの状態と一般ユーザーでログインした状態のどちらでも、「事務方」タブに「課を追加」が表示されない
- [ ] 管理者が「事務方人事を追加」で役職「審議官」、官職名「大臣官房審議官（テスト担当）」、人物、就任日を入力して保存すると、「審議官」の下にその官職名と氏名の行が表示される
- [ ] 審議官の人事で官職名を空のまま保存すると、「官職名は必須です」と表示され、追加されない
- [ ] 同じ省庁・同じ期間に審議官を 2 人登録しても、エラーにならず 2 行とも表示される
- [ ] 管理者が「課を追加」で所属「主計局」、課名「テスト課」を入力して保存すると、「事務方人事を追加」の役職の選択肢に「主計局テスト課長」が現れる
- [ ] 「課を追加」で課名を空のまま保存すると、「課名は必須です」と表示され、課は追加されない
- [ ] 同じ局に既にある課名「総務課」で「課を追加」を保存すると、「同じ名前の課が既にあります」と表示され、課は追加されない
- [ ] 在任者のいる期間に、同じ課の課長をもう 1 人追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、追加されない
- [ ] 追加した課長の人事は、その人物の人物ページの経歴に、役職名「主計局テスト課長」・所属「財務省」で表示される
- [ ] 追加した課・審議官・課長の人事は、開発サーバーを再起動した後も「事務方」タブに表示される
- [ ] 回帰: 財務省の「事務方」タブの「局長」の下に「主計局長」と氏名が表示される
