## Sprint 4: 内閣と閣僚人事の作成・修正（出典の編集）

### 目的
管理者が、新しい内閣を登録し、閣僚人事（誰がいつからいつまでどの役職に就いたか）を出典（URL・メモ）付きで追加・修正・削除できる。変更は内閣名簿と人物の経歴に即座に反映される。

### 実装する機能
- 内閣の追加・修正: 管理者が、内閣名・発足日・終了日（任意）を入力して内閣を追加し、内閣詳細画面から修正する
- 閣僚人事の追加: 管理者が内閣詳細画面で、役職を選び、人物を名前で検索して選び（その場で新しい人物も登録でき）、就任日・退任日・出典 URL・出典メモを入力して追加する
- 閣僚人事の修正・削除: 管理者が閣僚名簿の各行から、日付と出典を含めて人事を修正・削除する

### 対象外（このスプリントでやらないこと）
- 内閣官房副長官・副大臣・大臣政務官の人事（Sprint 5）
- 内閣そのものの削除
- 役職（閣僚ポスト）の追加・名称変更（閣僚の役職は初期データで用意したものから選ぶ）
- 出典の複数登録（1 つの人事に出典 URL 1 つとメモ 1 つ）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 未ログインの状態と一般ユーザーでログインした状態のどちらでも、内閣一覧に「内閣を追加」が、内閣詳細画面に「内閣を編集」「閣僚を追加」と名簿各行の「編集」「削除」が表示されない
- [ ] 管理者でログイン中に内閣一覧の「内閣を追加」から内閣名と発足日を入力して「保存」を押すと、その内閣が一覧の発足日順の位置に表示される
- [ ] 追加した直後の閣僚のいない内閣の詳細画面に、「登録された閣僚はいません」と表示される
- [ ] 内閣の追加画面で内閣名を空のまま「保存」を押すと、「内閣名は必須です」と表示され、内閣は追加されない
- [ ] 内閣の追加画面で発足日より前の終了日を入力して「保存」を押すと、「終了日は発足日以降の日付にしてください」と表示され、内閣は追加されない
- [ ] 「閣僚を追加」で役職を選び、人物欄に既存の人物の氏名の一部を入力して表示された候補を選び、就任日を入力して「保存」を押すと、閣僚名簿にその役職と氏名の行が追加される
- [ ] 「閣僚を追加」の人物欄に、どの人物にも一致しない名前を入力すると「新しい人物として登録」が表示され、よみがなを入力して登録すると、その人物が選択された状態になる
- [ ] 「閣僚を追加」で出典 URL に `https://example.com/source` 、出典メモに「テスト出典」を入力して保存すると、追加された行の「出典」リンク先がその URL になり、その人物の人物ページの経歴の行に「テスト出典」が表示される
- [ ] 「閣僚を追加」で出典 URL に「abc」と入力して「保存」を押すと、「出典URLは http:// または https:// で始まるURLを入力してください」と表示され、名簿に行が追加されない
- [ ] 「閣僚を追加」で内閣の発足日より前の就任日を入力して「保存」を押すと、「就任日は内閣の在任期間内にしてください」と表示され、名簿に行が追加されない
- [ ] 在任者のいる期間に、同じ内閣の「内閣官房長官」をもう 1 人追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、名簿に行が追加されない
- [ ] 閣僚名簿の行の「編集」で退任日と出典メモを変更して「保存」を押すと、新しい退任日と出典メモが、その人物の人物ページの経歴の行に表示される
- [ ] 閣僚名簿の行の「削除」を押し、確認ダイアログで「削除する」を押すと、その行が名簿から消え、その人物の人物ページの経歴からも消える
- [ ] 追加・修正した内閣と閣僚人事（出典を含む）は、開発サーバーを再起動した後も内閣一覧と内閣詳細画面に表示される
- [ ] 回帰: 管理者が経歴のある人物（例: 「林芳正」）のページで「削除」を押すと、「経歴が登録されている人物は削除できません」と表示され、人物ページが残る
