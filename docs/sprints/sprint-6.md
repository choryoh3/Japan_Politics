## Sprint 6: 省庁の事務方人事（事務次官以下）

### 目的
省庁ページで、事務次官・官房長・局長の歴代を確認でき、ログイン中のユーザーが事務方人事と部局（局）を追加・修正できる。

### 実装する機能
- 事務方タブ: 省庁ページに「事務方」タブを追加し、「事務次官」「官房長」「局長」の見出しごとに歴代在任者を就任日の新しい順で表示する
- 事務方人事の追加・修正・削除: 省庁ページから、事務次官・官房長・各局長の人事を追加・修正・削除する
- 部局の追加: 省庁ごとに局を追加し、その局の局長を役職として選べるようにする

### 対象外（このスプリントでやらないこと）
- 審議官・課長など局長より下の役職
- 部局の削除・名称変更
- 省庁の追加・名称変更

### 前提（初期データ）
- 財務省に事務次官の人事 2 件以上と、局 2 つ以上（例: 主計局）とその局長の人事を含める

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 財務省の省庁ページに「事務方」タブがあり、押すと「事務次官」「官房長」「局長」の見出しがこの順に表示される
- [ ] 財務省の「事務方」タブの「事務次官」の下に、2 名以上が就任日の新しい順で、氏名・就任日・退任日とともに表示される
- [ ] 「局長」の下の各行に、局名を含む役職名（例: 「主計局長」）と氏名が表示される
- [ ] 未ログインの状態では、「事務方」タブに「事務方人事を追加」「部局を追加」が表示されない
- [ ] ログイン中に「事務方人事を追加」の役職の選択肢に、「事務次官」「官房長」と、その省庁に登録された局の局長（例: 「主計局長」）が含まれる
- [ ] 「部局を追加」で局名「テスト局」を入力して保存すると、「事務方人事を追加」の役職の選択肢に「テスト局長」が現れる
- [ ] 「部局を追加」で局名を空のまま保存すると、「部局名は必須です」と表示され、局は追加されない
- [ ] 同じ省庁に既にある局名で「部局を追加」を保存すると、「同じ名前の部局が既にあります」と表示され、局は追加されない
- [ ] 在任者のいる期間に、同じ省庁の「事務次官」をもう 1 人追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、追加されない
- [ ] 追加した事務方人事は、その人物の人物ページの経歴に、所属欄が省庁名（例: 「財務省」）で表示される
- [ ] 事務方人事の行の「編集」で退任日を入力して保存すると、「事務方」タブの行に退任日が表示される
- [ ] 事務方人事の行の「削除」を押し、確認ダイアログで「削除する」を押すと、その行が「事務方」タブから消える
- [ ] 追加した部局と事務方人事は、開発サーバーを再起動した後も「事務方」タブに表示される
- [ ] 回帰: 内閣詳細画面に「閣僚」「内閣官房副長官」「副大臣」「大臣政務官」の 4 つの見出しが表示される
