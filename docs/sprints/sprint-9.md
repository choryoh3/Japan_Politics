## Sprint 9: 政務調査会の部会・調査会人事と党役職の追加

### 目的
自民党政務調査会の部会・調査会ごとに、部会長・調査会長などの在任者と歴代を実在データで確認でき、管理者が部会・調査会とその人事（出典を含む）、さらに 8 役職以外の党役職を追加できる。

### 実装する機能
- 部会・調査会の一覧とページ: 「部会」「調査会」の区分で一覧し、各ページで指定日時点の在任者と役職ごとの歴代を表示する
- 部会・調査会の追加と人事の追加・修正・削除: 管理者が部会・調査会を追加し、部会長・部会長代理・調査会長・事務局長の人事を出典付きで管理する
- 党役職の追加: 管理者が、党役員ページに表示する党役職（例: 選挙対策委員長）を追加する
- 実在の初期データの追加: データ投入時点の政務調査会の部会・調査会と、その長（部会長・調査会長）の在任者を、出典付きで投入する

### 対象外（このスプリントでやらないこと）
- 部会・調査会・党役職の削除と名称変更
- 部会・調査会の下の小委員会・プロジェクトチーム
- 党役職の表示順の並べ替え（追加した役職は末尾に表示する）
- 部会・調査会の歴代の長（データ投入時点より前の在任者）、部会長代理・事務局長の初期データ

### 前提（初期データ）
- 部会を 10 以上（「財務金融部会」「外交部会」「国防部会」を含む）、調査会を 3 以上（「税制調査会」を含む）登録する
- 登録したすべての部会に、データ投入時点の部会長の人事を、出典 URL 付きで登録する
- 出典 URL は自由民主党の公式ウェブサイト、または人事を報じた公式の発表のページとする

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 党役員ページの「政務調査会」リンクを押すと、「部会」の見出しの下に「財務金融部会」を含む 10 件以上、「調査会」の見出しの下に「税制調査会」を含む 3 件以上の名称が表示される
- [ ] 部会名を押すとその部会のページに移動し、今日時点の「部会長」と「部会長代理」の在任者（在任者がいなければ「空席」）が表示される
- [ ] 「財務金融部会」のページで、今日時点の「部会長」に氏名が表示され、その人事の「出典」リンク先 URL が `https://` で始まる
- [ ] 部会のページに部会長の歴代が就任日の新しい順に、氏名・就任日・退任日とともに表示される
- [ ] 未ログインの状態と一般ユーザーでログインした状態のどちらでも、「部会・調査会を追加」「人事を追加」「役職を追加」が表示されない
- [ ] 管理者が「部会・調査会を追加」で区分「部会」と名称「テスト部会」を入力して保存すると、「部会」の見出しの下に「テスト部会」が表示される
- [ ] 既にある部会と同じ名称「財務金融部会」で保存すると、「同じ名前の部会・調査会が既にあります」と表示され、追加されない
- [ ] 部会のページの「人事を追加」で役職「部会長」・人物・就任日を入力して保存すると、その人物が部会長の歴代の 1 行目に表示される
- [ ] 在任者のいる期間に同じ部会の「部会長」をもう 1 人追加しようとすると、「同じ期間にこの役職の在任者がいます」と表示され、追加されない
- [ ] 財務金融部会の部会長の人物ページの経歴に、役職名「財務金融部会長」と所属「自由民主党 政務調査会」が表示される
- [ ] ヘッダーの検索欄に「財務金融」と入力すると、「財務金融部会」が「部会・調査会」見出しの下に候補として表示され、選ぶと部会のページに移動する
- [ ] 管理者が党役員ページの「役職を追加」で「選挙対策委員長」を入力して保存すると、党役員ページの役職一覧の末尾に「選挙対策委員長」が表示され、在任者の欄に「空席」と表示される
- [ ] 「役職を追加」で既にある役職名「幹事長」を入力して保存すると、「同じ名前の役職が既にあります」と表示され、追加されない
- [ ] 追加した部会・調査会、その人事、党役職は、開発サーバーを再起動した後も表示される
- [ ] 回帰: 党役員ページで日付を「2025-01-01」にすると、「総裁」に「石破茂」と表示される
