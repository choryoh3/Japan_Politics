## Sprint 3: ログインと人物の作成・修正・削除

### 目的
ユーザーがアカウントを登録・ログインでき、ログイン中は人物を追加・修正・削除できる。未ログインのユーザーは閲覧だけができる。

### 実装する機能
- アカウント登録・ログイン・ログアウト: メールアドレスとパスワードで登録・ログインし、ヘッダーにログイン状態を表示する
- 人物の追加: 氏名・よみがな（必須）と生年月日・メモ（任意）を入力して人物を登録する
- 人物の修正: 人物ページから氏名・よみがな・生年月日・メモを修正する
- 人物の削除: 経歴が 1 件もない人物を、確認のうえ削除する

### 対象外（このスプリントでやらないこと）
- 内閣・人事（任命）の作成・修正・削除（Sprint 4）
- パスワード再設定、メールアドレスの確認メール送信、外部サービスでのログイン
- 管理者などの権限ロール（ログインしたユーザーは全員同じ権限）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 未ログインで任意のページを開くと、ヘッダーに「ログイン」リンクが表示される
- [ ] 登録画面で、表示名・メールアドレス・8 文字のパスワードを入力して「登録する」を押すと、ログイン状態になり、ヘッダーに表示名と「ログアウト」が表示される
- [ ] 登録画面で 7 文字のパスワードを入力して「登録する」を押すと、「パスワードは8文字以上にしてください」と表示され、ログイン状態にならない
- [ ] ログイン画面で誤ったパスワードを入力して「ログイン」を押すと、「メールアドレスまたはパスワードが違います」と表示される
- [ ] ヘッダーの「ログアウト」を押すと、ヘッダーの表示が「ログイン」リンクに戻る
- [ ] 未ログインの状態では、人物ページに「編集」「削除」ボタンが表示されず、ヘッダーに「人物を追加」が表示されない
- [ ] 未ログインの状態で人物の追加画面の URL を直接開くと、ログイン画面に移動する
- [ ] 未ログインの状態で人物を追加する API に直接リクエストを送ると、HTTP 401 が返り、人物は追加されない（API の URL は Generator の完了報告に記載する）
- [ ] ログイン中に「人物を追加」から氏名とよみがなを入力して「保存」を押すと、追加した人物のページに移動し、見出しに入力した氏名が表示される
- [ ] 人物の追加画面で氏名を空のまま「保存」を押すと、氏名欄の下に「氏名は必須です」と表示され、人物は追加されない
- [ ] 人物の追加画面でよみがなに「カタカナ」と入力して「保存」を押すと、「よみがなはひらがなで入力してください」と表示され、人物は追加されない
- [ ] 人物ページの「編集」で氏名を変更して「保存」を押すと、人物ページの見出しと、その人物が載る内閣詳細画面の閣僚名簿の両方に新しい氏名が表示される
- [ ] 追加・修正した人物は、開発サーバーを再起動した後も人物ページに表示され、ヘッダーの検索欄で氏名の一部を入力すると候補に出る
- [ ] 経歴が 0 件の人物のページで「削除」を押し、確認ダイアログで「削除する」を押すと、内閣一覧に戻り、検索欄でその氏名を入力しても候補に出ない
- [ ] 経歴が 1 件以上ある人物のページで「削除」を押すと、「経歴が登録されている人物は削除できません」と表示され、人物ページは残る
