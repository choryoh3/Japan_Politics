## Sprint 3: ログイン・管理者ロールと人物の作成・修正・削除

### 目的
ユーザーがアカウントを登録・ログインできる。管理者だけが人物を追加・修正・削除でき、一般ユーザーと未ログインの利用者は閲覧だけができる。最初の管理者をコマンドで作れる。

### 実装する機能
- アカウント登録・ログイン・ログアウト: メールアドレスとパスワードで登録・ログインし、ヘッダーにログイン状態を表示する。登録したユーザーは一般ユーザーになる
- 管理者ロール: 登録済みのアカウントを、メールアドレスを指定したコマンドで管理者にする。作成・修正・削除の画面と API は管理者だけが使える
- 人物の追加・修正: 管理者が、氏名・よみがな（必須。よみがなはひらがなのみ）と生年月日・メモ（任意）を入力して人物を登録し、人物ページから修正する
- 人物の削除: 管理者が、経歴が 1 件もない人物を、確認のうえ削除する（経歴のある人物は削除できない）

### 対象外（このスプリントでやらないこと）
- 内閣・人事（任命）と出典の作成・修正・削除（Sprint 4 以降）
- パスワード再設定、メールアドレスの確認メール送信、外部サービスでのログイン
- 画面からの管理者の付与・剥奪、管理者・一般ユーザー以外のロール

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 未ログインで任意のページを開くと、ヘッダーに「ログイン」リンクが表示される
- [ ] 登録画面で、表示名・メールアドレス・8 文字のパスワードを入力して「登録する」を押すと、ログイン状態になり、ヘッダーに表示名と「ログアウト」が表示される
- [ ] 登録画面で 7 文字のパスワードを入力して「登録する」を押すと、「パスワードは8文字以上にしてください」と表示され、ログイン状態にならない
- [ ] ヘッダーの「ログアウト」を押すと、ヘッダーの表示が「ログイン」リンクに戻る
- [ ] `docs/project.md` の「初期データ・準備」に管理者付与コマンドが記載され、登録済みのメールアドレスを指定して実行すると終了コード 0 で終わる
- [ ] 管理者付与コマンドで管理者にしたアカウントでログインすると、ヘッダーに「人物を追加」が表示される
- [ ] 未登録のメールアドレスを指定して管理者付与コマンドを実行すると、「該当するアカウントがありません」と出力され、終了コード 0 以外で終わる
- [ ] 未ログインの状態と、登録しただけの一般ユーザーでログインした状態のどちらでも、人物ページに「編集」「削除」が表示されず、ヘッダーに「人物を追加」が表示されない
- [ ] 未ログインの状態で人物を追加する API に直接リクエストを送ると、HTTP 401 が返り、人物は追加されない（API の URL は Generator の完了報告に記載する）
- [ ] 一般ユーザーでログインした状態で人物を追加する API に直接リクエストを送ると、HTTP 403 が返り、人物は追加されない
- [ ] 管理者でログイン中に「人物を追加」から氏名とよみがなを入力して「保存」を押すと、追加した人物のページに移動し、見出しに入力した氏名が表示される
- [ ] 人物の追加画面でよみがなに「カタカナ」と入力して「保存」を押すと、「よみがなはひらがなで入力してください」と表示され、人物は追加されない
- [ ] 管理者が人物ページの「編集」で氏名を変更して「保存」を押すと、人物ページの見出しと、その人物が載る内閣詳細画面の閣僚名簿の両方に新しい氏名が表示される
- [ ] 追加・修正した人物と管理者の権限は、開発サーバーを再起動した後も残り、人物ページに表示され、管理者のヘッダーに「人物を追加」が表示される
- [ ] 管理者が経歴 0 件の人物のページで「削除」を押し、確認ダイアログで「削除する」を押すと、内閣一覧に戻り、検索欄でその氏名を入力しても候補に出ない

### 変更履歴
- 2026-11-18: ユーザー回答（管理者ロールを追加）を受けて改訂。編集権限を「ログインしたユーザー全員」から「管理者だけ」に変更し、管理者付与コマンドと一般ユーザーの 403 の項目を追加。項目数の上限に収めるため、次の項目を契約から削除: 「誤ったパスワードでのログインエラー」「未ログインで追加画面の URL を開くとログイン画面へ移動」「氏名が空のときのエラー」「経歴のある人物の削除拒否」。氏名必須と、経歴のある人物は削除できない規則は「実装する機能」に残し、Generator は実装する（経歴のある人物の削除拒否は Sprint 4 の契約で確認する）。
