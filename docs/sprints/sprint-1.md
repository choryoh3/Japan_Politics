## Sprint 1: 歴代内閣の一覧と閣僚名簿の閲覧

### 目的
アプリを起動すると、初期データの歴代内閣を一覧でき、内閣を選ぶとその閣僚名簿（総理大臣・官房長官・各大臣）が見られる。DB から読み出す流れが端から端まで動く。

### 実装する機能
- 初期データの準備: DB の作成（マイグレーション）と、検証用の内閣・人物・閣僚人事の投入を、1つの手順で実行できるようにする
- 内閣一覧画面: トップページに歴代内閣を発足日の新しい順で表示する
- 内閣詳細画面: 内閣の名称・在任期間と、閣僚名簿（役職と氏名）を表示する

### 対象外（このスプリントでやらないこと）
- 人物ページ、検索（Sprint 2）
- ログイン、データの作成・修正・削除（Sprint 3 以降）
- 内閣官房副長官・副大臣・大臣政務官の表示（Sprint 5）
- 省庁ページ、党人事（Sprint 5 以降）
- ライト / ダーク切替（Sprint 2）

### 前提（初期データ）
- 内閣を 3 件以上含み、そのうち 1 件は終了日のない（在任中の）内閣とする
- 各内閣に、内閣総理大臣・内閣官房長官を含む 5 件以上の閣僚人事を含む

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] `docs/project.md` の「初期データ・準備」に、DB の作成と初期データ投入のコマンドが記載されている
- [ ] `local.db` が無い状態で、記載のコマンドを順に実行すると、すべて終了コード 0 で終わる
- [ ] 初期データ投入コマンドを 2 回続けて実行しても、内閣一覧に表示される内閣の件数が増えない
- [ ] `pnpm dev` で起動して `http://localhost:3000/` を開くと、見出し「歴代内閣」と 3 件以上の内閣の一覧が表示される
- [ ] 内閣一覧の各行に、内閣名・内閣総理大臣の氏名・発足日・終了日の 4 項目が表示される
- [ ] 終了日のない内閣は、一覧の終了日欄に「現在」と表示される
- [ ] 内閣一覧は発足日の新しい順に並び、1 行目は発足日が最も新しい内閣である
- [ ] 内閣一覧で内閣名をクリックすると、その内閣の詳細画面に移動し、見出しに内閣名が表示される
- [ ] 内閣詳細画面に、発足日と終了日（在任中は「現在」）が「YYYY年M月D日」の形式で表示される
- [ ] 内閣詳細画面の閣僚名簿に、役職名と氏名の組が 5 行以上表示される
- [ ] 閣僚名簿の 1 行目の役職は「内閣総理大臣」、2 行目の役職は「内閣官房長官」である
- [ ] 存在しない内閣 ID の詳細画面の URL を直接開くと、「内閣が見つかりません」と表示され、内閣一覧へ戻るリンクがある
- [ ] 開発サーバーを停止して再起動し、トップページを開くと、停止前と同じ件数の内閣が表示される
- [ ] トップページの `html` 要素の `lang` 属性が `ja` である
